# Benchmark definitions

`manifests/` contains the frozen graph/task identities, generation seeds,
resource budgets and discovery/held-out splits. Configs beside `src/` specify
generator distributions, graph templates, objective settings and optimizer
budgets. These are synthetic RCSP instances generated by project code; no
external dataset is downloaded.

Run `python scripts/materialize_release_tasks.py` from the repository root to
recreate 140 corrected instances and 180 Phase-3 instances in a new external
workspace, checking graph IDs, task IDs, feasible/optimal counts and costs.
Instance JSON files are generated inputs and need not be tracked separately.
Canonical measurements stay under `results/`; new timings are not frozen data.
