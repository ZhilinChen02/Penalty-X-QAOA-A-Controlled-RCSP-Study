# Figure and Table Plan

The main paper uses six figures and four tables. Theory-validation plots and
full cost ledgers move to the supplement. Historical visuals are source assets,
not automatically publication figures.

## Main figures

1. **F1 -- Access-model distinction.** Explicit RCSP versus edge-bit state
   representation versus route-attribute query domain. Every panel labels input
   length and charged access (`C-T5`, `C-T7`, `C-LIM-MODELS`).
2. **F2 -- Representation counterexample.** Unique chain plus serial
   subdivision, showing explicit output cost beside
   \(\phi_{\rm state}^{-1/2}\) (`C-T5`, `C-T6`).
3. **F4 -- Necessary structure--query tradeoff.** Contours of
   \(b_{\rm eff}+2\log_2(2q+1)\) with an explicit “necessary, not sufficient”
   annotation (`C-T8`, `C-T9`, `C-T11`).
4. **F5 -- Frozen evidence pipeline.** Construction/scale control, discovery,
   optimizer attribution, held-out confirmation, and scaling response in
   distinct colors (`C-E0-UNIVERSE` through `C-E4-OBJDISC`).
5. **F6/F7 -- Held-out result and decomposition.** Graph-paired H1/H2 panel
   followed by \(P_{\rm opt}=P_{\rm feas}P_{\rm opt\mid feas}\). O2 is labeled
   a mechanistic ceiling (`C-E5-H1`, `C-E5-H2`, `C-E5-POPT`, `C-E5-TAIL`).
6. **F8 -- Scaling response.** Development/interpolation/extrapolation with
   m=20 reversal and m=22 censoring visible; no extrapolated law line
   (`C-E6-SCALING`, `C-E6-BOTTLENECK`).
7. **F9 -- Cost relocation map.** Information, preprocessing, state
   preparation, mixer, query and validation resources retain separate evidence
   statuses (`C-COST`).

F6 and F7 may be combined if page pressure demands it. F2 may move to the
theory-boundary section rather than the empirical sequence.
